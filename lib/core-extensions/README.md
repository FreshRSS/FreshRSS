# FreshRSS core extensions

This directory contains some core extensions shipped with FreshRSS:

* `UserCSS`: [User CSS](https://freshrss.github.io/FreshRSS/en/users/05_Configuration.html#user-css)
* `UserJS`: [User JS](https://freshrss.github.io/FreshRSS/en/users/05_Configuration.html#user-js)

For custom third-party extensions, use the `./FreshRSS/extensions/` directory instead.
